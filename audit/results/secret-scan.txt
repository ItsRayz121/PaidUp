Sanitized secret scan
Date: 2026-09-03
Commit: 8bc95ac1a97780c7962694cd6ccbb3e920b93e83

Method:
- Enumerated tracked filenames for .env, PEM, key, keystore, credential and secret names.
- Searched tracked source/config/docs for common private-key, bearer-token and provider-key
  assignment patterns.
- Reviewed matches by filename and code context without copying values into this artifact.

Outcome:
- Tracked environment-style file: .env.example only.
- Private-key-shaped matches were implementation patterns in the EVM adapter and synthetic
  test fixtures, not a confirmed committed live key.
- No confirmed committed live secret was found.

Limit: this is a repository pattern scan, not git-history scanning, provider-side secret
inventory, runtime environment inspection, or proof that a value has never leaked.
